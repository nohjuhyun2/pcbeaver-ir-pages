# PCBeaver 60초 IR

GitHub Pages로 배포되는 PCBeaver HTML 자료 모음입니다.

온라인에서 수정하려면 GitHub에서 해당 HTML 파일을 열고 **Edit this file**을 선택한 뒤 변경 사항을 커밋하세요. 커밋 후 Pages 주소에 자동 반영됩니다.

## 파일 구성

- `index.html`: 자료 목록의 첫 화면
- `pcbeaver_ir_60s.html`: 60초 IR 발표 자료

새 자료를 추가할 때는 HTML 파일을 올리고 `index.html`에 해당 파일로 연결되는 카드를 추가하세요.
